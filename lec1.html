1강 · 선형계획 (Linear Programming)

1모형의 네 조각

개념 Linear Programming (선형계획, LP)

  • 제약 안에서 목표를 최대/최소로 만드는 문제 중, 목적함수와 제약이 전부 1차식인 것 — 제곱이나 변수끼리의 곱이 없다.
  • 변수가 정수만 허용되면 Integer Programming(정수계획)이라 훨씬 어려워진다. 이 수업은 연속 변수만 다룬다.

모형의 네 조각

  • Decision Variable(결정변수): 내가 정하는 것. 예: Basic을 몇 개 만들지.
  • Objective Function(목적함수): 최대화할 것(이익, 도달) 또는 최소화할 것(비용).
  • Constraint(제약): 노동·재료·예산·수요 한도. 음수 불가(non-negativity)도 제약이다.
  • Feasible Region(실행 가능 영역): 모든 제약을 동시에 만족하는 점들의 집합.

왜 이렇게 생각하는가 — 교수님 설명

  • "오늘이 학기 중 가장 어려운 수업" (수학이 조금 나와서).
  • 자원이 무한하면 그냥 많이 만들면 된다. 현실의 결정은 늘 예산·노동·수요에 막힌 상태에서의 선택이다.
  • 문제를 읽는 순서: 마케팅 문제 이해 → 결정변수 → 목적함수 → 제약. "문제를 해석해서 변수를 정의하는 게 중요하다. 그다음은 엑셀에 넣고 해 찾기를 누르면 된다."
  • 제조 쪽은 보통 비용 최소화, 경제학은 이익 최대화로 본다.

2예제 1 — Basic과 Premium 생산

노동 100시간, 재료 90단위. Basic은 노동 2시간·재료 3단위에 이익 $30, Premium은 노동 4시간·재료 2단위에 이익 $50. 몇 개씩 만들어야 하나?

  1. 모형 세우기결정변수 = Basic 개수, = Premium 개수. 목적함수 최대화. 제약: 노동 2x₁+4x₂ ≤ 100, 재료 3x₁+2x₂ ≤ 90, x₁,x₂ ≥ 0. 이유: 문제의 숫자를 목표(이익)와 한계(자원)로 나누는 것이 LP 모형화의 전부다.
  2. 실행 가능 영역 그리기각 제약을 등호로 놓으면 직선이 된다. 노동선은 (0, 25)~(50, 0), 재료선은 (0, 45)~(30, 0)을 잇는다. 두 선 아래쪽 + 1사분면이 실행 가능 영역. 이유: 부등식 제약 = 그 직선의 한쪽 면이라는 뜻.
  3. 꼭짓점만 비교꼭짓점 네 개에 Z를 대입한다 (아래 표). 이유: 꼭짓점 원리 — 최적해가 존재하면 꼭짓점 중에 반드시 있다. Simplex(해 찾기)도 이 꼭짓점을 따라 이동하는 알고리즘이다.
  4. 답과 검산최대는 (20, 15)의 $1,350. 노동·재료를 둘 다 정확히 다 쓴다 (2·20+4·15=100, 3·20+2·15=90). 이유: 최적해에서 여유가 남은 제약은 그 자원이 비싸지 않다는 뜻(아래 그림자 가격).
꼭짓점 (x₁, x₂)Z = 30x₁ + 50x₂비고
(0, 0)$0
(30, 0)$900재료 한계
(0, 25)$1,250노동 한계
(20, 15)$1,350최적 — 두 자원 모두 소진

그림자 가격: 제약을 풀면 얼마가 남는가

개념 Shadow Price(그림자 가격) = 라그랑주 승수 λ

  • 제약을 한 단위 풀어 줄 때 최적 목표값이 늘어나는 양 = 그 자원의 가치.
  • 시장에서 그 자원을 그보다 싸게 살 수 있으면 사는 게 이득이다.
λ₁ = 11.25
노동 1시간의 가치 — 초과근무 시급이 $11.25보다 싸면 고용
λ₂ = 2.50
재료 1단위의 가치 — 급행 주문이 이보다 비싸면 손해
검산 — 승수가 맞으면 자원 가치의 합 = 최적 이익

주의 시험에 나오는 해석

  • λ는 지금 상태에서 한 단위의 가치다. "몇 시간까지 사도 되나?"라는 질문에는: 사고 나면 문제가 바뀌니 다시 풀어야 한다.
  • 교수님 질문: "경기가 좋으면 기업이 사람을 더 뽑는 이유?" → 노동의 그림자 가격이 시급보다 커져서.

3예제 2 — 카페: 진짜 제약은 수요

커피 이익 $2(준비 4분), 차 $1.5(2분). 하루 주방 시간 240분, 하루 수요 합계 60잔(시장 크기).

  1. 모형 세우기x₁ = 커피, x₂ = 차. 최대화. 제약: 시간 4x₁+2x₂ ≤ 240, 수요 x₁+x₂ ≤ 60. 시장보다 많이 만들 이유가 없으니 수요도 제약으로 둔다.
  2. 그래프 읽기수요선이 시간선보다 거의 전부 아래에 있고 (60, 0)에서만 만난다. 실행 가능 영역은 꼭짓점 셋짜리 삼각형. 해석: 주방 시간이 아니라 수요가 진짜 제약 — 시간은 사실상 안 묶인다.
  3. 꼭짓점 비교(0, 0) = $0, (0, 60) = $90, (60, 0) = $120. (30, 30)은 수요선 위에 있지만 꼭짓점이 아니라 볼 필요가 없다 (봐도 $105).

답과 직관

  • 커피만 60잔, 이익 $120 — 240분을 전부 커피에 쓴다.
  • 직관: 손님 한 명이 차를 커피로 바꾸면 분당 이익이 늘고, 반대는 손해 → 커피만 판다.

4예제 3 — 광고 배분과 KKT

TV 1회 도달 100에 $2,000, SNS 1회 도달 80에 $1,000. 예산 $20,000, 최소 8회 노출.

  1. 모형 세우기x₁ = TV, x₂ = SNS. 최대화. 제약: 예산 2000x₁+1000x₂ ≤ 20,000, 노출 x₁+x₂ ≥ 8. 최소 노출은 ≥ 방향 제약 — 실행 가능 영역이 위·아래 양쪽에서 눌린다.
  2. 그래프 읽기예산선 (0, 20)~(10, 0)이 위쪽 경계, 노출선 (0, 8)~(8, 0)이 아래쪽 경계. 두 선은 (12, −4)에서 만나는데 영역 밖이라, 실행 가능 영역은 꼭짓점 (0, 8), (8, 0), (10, 0), (0, 20)의 사각형.
  3. 꼭짓점 비교(0, 8) = 640, (8, 0) = 800, (10, 0) = 1,000, (0, 20) = 1,600 → TV 0회, SNS 20회, 도달 1,600. 달러당 도달이 SNS가 높기 때문이다.

왜 그냥 라그랑주는 여기서 실패하는가 KKT 조건

  • 두 제약을 전부 등호로 묶어 풀면 λ₂ = −60이 나오고 교점 (12, −4)도 불가능한 점이다. 부등식 제약의 승수는 음수일 수 없다.
  • KKT 처리: 노출 제약은 최적해에서 여유(20회 > 최소 8회) → 승수 λ₂ = 0. 예산 승수 λ₁ = 0.08 = 예산 $1당 도달 0.08 증가.
  • 검산:
  • TV를 억지로 1회 넣으려면 $2,000이 필요해서 SNS 2회(도달 160)를 빼야 하고, TV 도달 100을 얻으니 순손해 60 — 이것이 의 의미.

5시험 포인트 정리

  • 음수 불가 제약을 빼먹으면 영역이 달라진다.
  • 최적해 비교는 꼭짓점만 — 변 위의 임의 점을 볼 필요가 없다.
  • 여유 있는 제약(다 안 쓴 자원)의 승수는 0 — 이걸 무시하고 모든 제약을 등호로 묶으면 음수 승수가 나온다 (KKT).
  • 그림자 가격의 단위는 "목표 단위 / 자원 단위" — 해석 문제로 자주 나온다.

수업 토론 — 음의 가격도 가능한가?

  • 전력 과잉 생산 때 전기를 쓰면 오히려 돈을 받는 경우가 있고(학생 답), 쓰레기는 내가 돈을 내고 "공급"한다 → 음의 재화.
  • 일반 재화는 가격 ≥ 0 제약을 둔다.

LP = 변수·목표·제약을 1차식으로 쓰는 것. 최적해는 꼭짓점에 있고, 승수는 자원의 가치를 말해 준다. 실전에서는 해 찾기가 계산하고, 우리는 모형을 세우고 결과를 해석한다.
