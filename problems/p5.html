거듭제곱 수요의 계수

4강 수요와 가격 · 목표값 찾기(Goal Seek)

문제 5수업 예제 (기출 아님)

거듭제곱 수요 를 가정한다. 현재 가격 에 500개가 팔릴 때 계수 를 구하고, 엑셀 목표값 찾기로 같은 값을 구하는 순서를 쓰라.

힌트
  • 현재 점 (100, 500)을 식에 그대로 대입하면 미지수는 a 하나뿐이다.
  • 엑셀: 데이터 → 가상 분석 → 목표값 찾기. 수식 셀, 찾는 값, 바꿀 셀 세 개만 채운다.
정답

개념은 위 힌트 참고.

  1. 대입. 지수 −2는 탄력성 −2에 해당.
  2. 풀기. 검산: . 손계산이 되면 목표값 찾기 결과를 검증하면 된다.
  3. 엑셀 순서① E3에 아무 시작값 ② E4에 가격 100, E5에 =E3*E4^(-2) ③ E5 선택 → 데이터 → 가상 분석 → 목표값 찾기 ④ 수식 셀 E5, 찾는 값 500, 바꿀 셀 E3 ⑤ 확인 → a = 5,000,000. 함수 꼴은 사람이 가정한다. 요즘은 알고리즘이 찾기도 한다.
