개념 대표값과 표준편차

  • 대표값 세 가지: 평균·중앙값·최빈값 (케이크 86.28 / 85 / 90).
  • Standard Deviation(표준편차): 분산의 제곱근이라 단위가 원래대로. 평균이 같아도 퍼짐이 다르면 예측 가능성이 다르다.
분산 (표본)

개념 Empirical Rule(경험 규칙)

분포가 심하게 치우치지 않으면 ±1σ 안에 약 68%, ±2σ에 약 95%, ±3σ에 약 99.7%. ±2σ 밖 = 이상값으로 따로 본다.

±2σ 95%
45.7 ~ 126.8개
±3σ 99.7%
25.4 ~ 147.1개

케이크 기준 (평균 86.28, 표준편차 20.28). 교재는 하한을 45.3으로 적었지만 계산하면 45.7. 산술은 인쇄물이 아니라 계산을 믿는다. 케이크 45개 미만이나 127개 넘게 팔린 날은 따로 볼 만하다.

2경험 규칙을 COUNTIF로 확인하기

  1. 하한·상한 계산=H7-2*H10, =H7+2*H10 → 45.7, 126.8. H7 = 평균, H10 = 표준편차 셀.
  2. 아래쪽 이상값 세기=COUNTIF(Cake,"<"&R15) → 13일. 비교 기호는 글자라 따옴표 안에, 셀 값은 &로 붙인다. 따옴표 안에 R15를 쓰면 글자 자체를 찾는다.
  3. 위쪽 이상값 세기=COUNTIF(Cake,">"&R16) → 35일.
  4. 안쪽 비율 확인전체 =COUNT(Cake) = 1,095일 → 1,095 − 13 − 35 = 1,047일 = 95.62%. 규칙의 95%와 거의 같다.

3조건부 집계: 요일별 케이크

요일별 표 (Q32:Q38에 Monday…Sunday)를 채우는 네 식:

  • 며칠: =COUNTIF($E$12:$E$1106, Q32)
  • 총판매: =SUMIF($E$12:$E$1106, Q32, Cake) (인수 순서: 조건 범위, 조건, 더할 범위)
  • 평균: 총판매 ÷ 일수, 또는 =AVERAGEIF($E$12:$E$1106, Q32, Cake)로 한 번에
  • 순위: =RANK(T32, $T$32:$T$38, 0) (끝이 0이면 큰 값이 1등, 범위는 F4($)로 고정)

수업에서 나온 질문

  • "판매 0인 월요일도 세나?" → COUNTIF는 센다. 빼려면 =COUNTIFS(E12:E1106, Q32, Cake, "<>0")처럼 조건 추가.
  • 월별 평균은 AVERAGEIFS인데 범위 모양 문제가 있어 MATCH, INDEX를 소개 → 숙제로 나옴.

4인수 순서 함정 (가장 흔한 실수)

시험 함정 SUMIF vs SUMIFS: 요약 범위의 위치가 뒤집힌다

단수형복수형
=SUMIF(조건 범위, 조건, 합계 범위): 합계 범위가 셋째=SUMIFS(합계 범위, 조건 범위1, 조건1, …): 합계 범위가 첫째
=AVERAGEIF(범위, 조건, 평균 범위): 셋째=AVERAGEIFS(평균 범위, 조건 범위1, 조건1, …): 첫째
COUNTIF·COUNTIFS는 예외: 요약할 열이 없어서 범위·조건 쌍만 쓴다
  • AVERAGEIFS는 모든 범위가 같은 모양이어야 한다 (여러 열짜리 표를 평균 범위로 넣으면 에러).
  • 수업 파일 함정: 라벨이 "Days sold>=122"인데 식은 ">122" → >는 122 제외, >=는 포함. 문제의 "이상/초과"를 잘 읽자.

5조회 함수: VLOOKUP · HLOOKUP · MATCH · INDEX

개념 VLOOKUP: 세로 표에서 찾기

=VLOOKUP(찾을 값, 표, 몇 번째 열, 정확히?): 표의 첫 열에서 찾고, 표 왼쪽부터 센 열의 값을 돌려준다. 교수님: "이 수업에서 제일 중요한 함수는 VLOOKUP, HLOOKUP".

  • 예: =VLOOKUP(F12, $A$13:$B$19, 2, FALSE): WEEKDAY로 나온 요일 번호를 "1~7, 요일 이름" 표에서 찾아 2번째 열 → 2면 Tuesday.
  • 열 번호는 시트가 아니라 표 왼쪽부터 센다.

개념 HLOOKUP: 가로 표에서 찾기

같은 함수인데 첫 행에서 찾고 아래 몇 번째 행 값을 준다. 표가 진짜 가로로 놓일 때만 사용 (예: 5강 Verizon 가격표. 윗행 상품 번호 1~7, 아랫행 가격). 표 범위를 $로 안 묶으면 77명 아래로 끌 때 표가 같이 내려가서 둘째 줄부터 틀린다.

시험 함정 넷째 인수: FALSE(0) vs TRUE(1)

FALSE / 0 = 정확히 일치TRUE / 1 = 근사(기본값!)
없으면 #N/A. 정렬 필요 없음. 거의 항상 이것. 기본값이 아니라 직접 써야 한다.찾는 값 이하 중 가장 큰 항목. 첫 열이 오름차순이 아니면 조용히 틀림. 세율·수량 할인·학점 구간표용.

흔한 오류 넷: ① #N/A (값이 없거나 공백, 숫자가 텍스트) ② 엉뚱한 열 (열 번호를 시트 기준으로 셈) ③ 복사하면 틀어짐 (표를 $로 안 묶음) ④ 조용히 틀린 값 (근사 일치 + 정렬 안 된 표).

개념 MATCH와 INDEX

  • =MATCH(값, 범위, 0): 범위에서 몇 번째인지. 예: =MATCH("Pies", $H$11:$L$11, 0) = 2. 마지막 인수: 0 = 정확히(수업은 항상 0) / 1 = 이하 중 최대(오름차순 필요) / −1 = 이상 중 최소 / 생략하면 1 → Verizon에서 학생들 매출이 달랐던 원인이 이 생략.
  • =INDEX(표, 행, 열): 그 위치의 값. 행에 0을 넣으면 그 열 전체.

6시험 포인트 정리

  • 비교 기호 + 셀 값: "<"&R15: 따옴표와 & 조합.
  • SUMIF(셋째) vs SUMIFS(첫째) 인수 순서.
  • VLOOKUP 넷째 인수는 직접 FALSE로. MATCH 셋째 인수는 0으로. 생략 = 근사 = 조용히 틀림.
  • 표 범위는 F4로 고정 ($A$13:$B$19). 아래로 끌 때 밀리지 않게.
  • 이름 붙인 범위는 끌어도 안 움직인다. 그래서 =MODE(Cake)를 오른쪽으로 끌면 다른 제품 칸도 계속 Cake (수업에서 실제로 나온 실수). 제품별로 옆으로 끌 땐 H12:H1106 같은 일반 범위로.
