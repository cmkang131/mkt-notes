1기본 조작

함정 — 수업에서 실제로 나온 실수
  • 이름 붙인 범위는 끌어서 복사해도 안 움직인다 ($ 안 붙여도 됨). 그래서 =MODE(Cake)를 오른쪽으로 끌면 다른 제품 칸도 계속 Cake → 제품별로 옆으로 끌 땐 H12:H1106 같은 일반 범위로.
  • 교수님이 수업 중 실수: 수요표 만들 때 a와 탄력성 셀을 고정 안 해서 아래로 끌자 값이 틀어짐 → 바뀌어야 하는 건 가격뿐, 나머지 상수 셀은 $로 고정.
  • 함수 이름 일부 치고 Tab → 이름과 여는 괄호가 같이 들어감 / Shift+클릭 = 여러 칸 선택.

2피벗 테이블

  • 만들기: 데이터 안에 커서 → 삽입 → 피벗 테이블 → 범위 자동 인식 → 새 워크시트 (기존 워크시트도 선택 가능). 필드는 체크만 해도 자동 배치되고 끌어도 됨.
  • 필드를 행 / 열 / 값 / 필터로 끌어 넣음 — 질문부터 정하고 넣을 자리를 고른다.
  • 숫자 필드는 기본이 합계 → 값 우클릭 → 값 필드 설정 → 개수 / 평균. 값에 제품 다섯 개를 넣었으면 다섯 개 각각 평균으로 바꿔야 함 (Bakery 요일별: 합계 그대로면 일요일 케이크 15,054처럼 나옴).
  • 비율: 값 필드 설정 → 값 표시 형식 → 열 합계 비율 / 행 합계 비율. 같은 필드를 값에 두 번 넣으면 금액과 비율을 나란히 볼 수 있음.
비율 세 가지 구분 — 무엇을 분모로 할지 먼저 정하기
  • 열 합계 비율: 열마다 100% / 행 합계 비율: 행마다 100% / 총합계 비율: 표 전체가 100%
  • 필드를 행에 놓으면 열 합계 비율, 열에 놓으면 행 합계 비율을 본다.
  • 행에 필드 두 개: 위에 둔 필드가 바깥 그룹 (예: Gender 아래 Location → 남·여 × 거주지 6칸). 두 번째 필드를 열에 두면 교차표.
  • Yes/No 같은 텍스트 필드를 값에 넣으면 자동으로 개수.
  • 특정 값만 보기: 필터 칸에 넣고 드롭다운에서 Yes만 선택 → 남은 데이터 안에서 비율이 다시 계산됨.
  • "무엇이 더 중요한 요인인가"류 질문: 요인을 행에, 결과(Yes/No)를 열에 두고 행 합계 비율 → 요인 값마다 Yes 비율이 얼마나 벌어지는지 비교.
  • 그룹: 행 레이블 우클릭 → 그룹 → 시작, 끝, 간격. ESPN 나이: 시작 8, 간격 10. 소득: 파일 단위가 천 달러라 간격 25, 시작 29. 날짜: 계절성은 월만, 해마다 추세는 연.
  • 상위 N: 행 레이블 드롭다운 → 값 필터 → 상위 10 → 숫자 80, 항목 백분율 → 매출 80% 내는 제품만.
  • 필터 vs 슬라이서: 필터는 뭘 골랐는지 잘 안 보임. 슬라이서: 피벗 안에 커서 → 삽입 → 슬라이서 → 필드 체크. 열 개수: 슬라이서 선택 → 슬라이서 탭 → 단추 → 열.

3날짜와 조회 함수 (Bakery)

  • 요일 번호: =WEEKDAY(G12, 2) → 월=1 … 일=7. 두 번째 인수: 1 = 일요일 1…토요일 7 / 2 = 월요일 1…일요일 7 / 3 = 월요일 0…일요일 6.
  • 요일 이름: =VLOOKUP(F12, $A$13:$B$19, 2, FALSE) — A13:B19에 1~7과 요일 이름 표를 만들어 둠.
  • 월: =MONTH(G12) → =VLOOKUP(N12, $A$22:$B$33, 2, FALSE)로 월 이름.

조회 함수 함정 (3강 정리 복습)
  • 넷째 인수 FALSE/0 = 정확히 일치 — 거의 항상 이것, 기본값이 아니라 직접 써야 함. TRUE/1 = 근사 (정렬 안 되면 조용히 틀림).
  • MATCH(값, 범위, 0) — 마지막 0 생략하면 1(근사) → Verizon에서 학생들 매출이 달랐던 원인.
  • HLOOKUP은 가로 표 (Verizon 가격표) 전용. 표 범위를 $로 안 묶으면 아래로 끌 때 둘째 줄부터 틀림.
  • INDEX(표, 행, 열), 행에 0 → 그 열 전체. MATCH+INDEX로 AVERAGEIFS 열을 고르는 식은 숙제 문제.

4요약 함수 (Bakery)

  • =AVERAGE(H12:H1106), MEDIAN, MODE, STDEV → 오른쪽으로 끌면 다른 제품도 (이름 범위 Cake로 넣으면 안 바뀜 — 위 함정).
  • =LARGE($H$12:$H$1106, 5) → 5번째로 큰 판매량 (케이크 148) / =SMALL(..., 3) → 3번째로 작은 값 (38).
  • COUNTIF 연습: 프로모션 날 수 =COUNTIF($M$12:$M$1106, $Q23) (Q23에 promotion), =COUNTIF(Cake, ">=120"), 이하는 "<=".
  • 조건 여러 개: =COUNTIFS(E12:E1106, Q32, Cake, "<>0") → 월요일이면서 판매 0이 아닌 날 (학생 질문에서 나옴).
  • 요일 일수: 월·금·토·일 156일, 화·수·목 157일.

5차트, 추세선, 목표값 찾기 (9/23 파일)

  • 수요표: =$K$3*J7^($G$1)을 가격 50~150 옆에 채우고 차트로 그린 것 (a는 아래 목표값 찾기로 구함).
  • 두 번째 점 만들기: 가격 =E4*(1+0.01), 수량 =F4*(1+G1/100) (G1 = 탄력성 −2) → (100, 500), (101, 490).
  • 차트: 두 점 선택 → 삽입 → 추천 차트 → 분산형 (엑셀은 x = 가격, y = 수량으로 식을 보여줌 → 가격 열이 왼쪽).
  • 추세선: 점 우클릭 → 추세선 추가 → 선형 → 맨 아래 차트에 수식 표시 → q = 1500 − 10p. 2차 수요(ChapStick)는 다항식 차수 2. 거듭제곱 추세선도 있음 → 두 방법으로 서로 검산 가능.

취소확인
  • Sheet2 (면도기): 탄력성 셀(G1)에 이름 Elas를 붙여서 =G5*(1+Elas/100) → (5, 6), (5.05, 5.88) → 같은 방법으로 추세선 q = 18 − 2.4p.
  • 추세선 식을 수량 셀에 직접 입력: G9 =18-2.4*G8 — 이게 없으면 해 찾기가 가격을 바꿔도 이익이 안 변함. 탄력성 바꾸면 추세선 새로 구해서 이 식도 다시 침 (−0.3이면 q = 7.8 − 0.36p).

6해 찾기 (Solver)

  • 설치: 파일 → 옵션 → 추가 기능 → 아래 관리 Excel 추가 기능 → 이동 → 해 찾기, 분석 도구 체크 (VBA는 안 씀). 위치: 데이터 탭 오른쪽 끝.
  • 설정 세 가지: 목표 셀 (최대/최소/지정값) / 변수 셀 (여러 칸 가능) / 제약 (추가 버튼).
  • 변수 셀이 떨어져 있으면 "변수 셀 변경" 칸에 쉼표로 입력 ($G$8,$G$20) 또는 Ctrl(맥은 Cmd) 누른 채 클릭.
  • "제한되지 않는 변수를 음이 아닌 수로" 체크 = 가격 ≥ 0.
  • 해법은 문제에서 알려줌 (교수님). 이익 식은 (P−C)×Q처럼 아무 형태로 써도 됨.
  • 정수 제약: 제약 추가에서 int → 단, 면도기 수요처럼 다른 셀의 함수인 셀은 정수로 못 묶음 (교수님 시연).
  • 거듭제곱 수요로 돌릴 때: 가격 셀이 0이면 #DIV/0! → 시작값을 양수로. 결과가 이상하면 시작값 바꿔 한 번 더.

메뉴 경로 모음
  • 피벗 테이블: 삽입 → 피벗 테이블 / 값 필드 설정: 값 칸 우클릭 / 그룹: 행 레이블 우클릭 / 슬라이서: 삽입 → 슬라이서

  • 추세선: 차트 점 우클릭 → 추세선 추가 → 차트에 수식 표시
